Agama Wallet runs on Windows, macOS and Linux, holds KMD, VRSC, BTC, LTC, ZEC, DOGE, BCH, DASH and ERC-20 tokens, and swaps between those chains inside the wallet rather than on an exchange. This page collects the guides published across the project's repositories.
